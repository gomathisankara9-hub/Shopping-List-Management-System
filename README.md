Shopping List Management System

About the Project

This is a simple C++ project used to manage shopping items.

Features

- Add an item
- Remove an item
- Search for an item
- Display all items
- Exit the program

Technologies Used

- C++
- Vector Data Structure

How to Run

1. Download the shopping_list.cpp file.
2. Open it using a C++ compiler.
3. Compile and run the program.
4. Select an option from the menu.

Learning Outcomes

- Learn basic C++ programming.
- Understand insertion and deletion.
- Learn searching operations.
- Understand vectors.
